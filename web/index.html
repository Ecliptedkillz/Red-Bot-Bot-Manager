FLEET MANAGEMENT

Create a bot

Separate IDs with commas or spaces. These trusted users receive Redbot owner permissions, matching --co-owner in your original launcher.

Enable Message Content Intent in the Discord Developer Portal for prefix commands. Bot setting changes require stopping the bot.

PERSISTENT CONFIGURATION

Cog settings

Saved as JSON. Cogs can read these settings through bot.cog_store(module_name).

BRING YOUR BOTS

Import a Redbot instance

Select a folder on the server containing core/settings.json and cogs/. The manager copies tokens, prefixes, installed cogs, libraries, and saved data. Your original stays untouched.

Import one instance at a time. Stop the original before importing to get a consistent copy, and keep it stopped before starting the imported copy.
